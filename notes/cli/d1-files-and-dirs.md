## 我敲过的 6 类命令

| 命令 | 作用 | 我怎么用的 |
|---|---|---|
| `pwd` | 告诉我在哪个目录 | 确认 `~/cli-practice/2026-09-06/` |
| `ls -la` | 当前目录所有文件（-l 详细、-a 含隐藏） | 看新目录搭出来的样子 |
| `cd ..` / `cd ../..` | 进上级 / 跳两层 | 反复确认路径 |
| `mkdir -p` | 建（嵌套）目录 | 一次性建 `a/b/c`、`data/docs/logs` |
| `echo > / >>` | 写文本（覆盖/追加）| 写 notes.md |
| `cat` | 把文件内容打印出来 | 看 notes.md 是不是写对了 |
| `touch` | 建空文件 / 改时间戳 | 验 `stat` 元信息 |
| `cp / mv` | 复制 / 重命名 | 拷贝出 v1 版本 |

## 容易踩的坑

| 坑 | 例子 | 解药 |
|---|---|---|
| 路径带空格 | `cd My Documents` 会失败 | `cd 'My Documents'` 或 `cd My\ Documents` |
| 重定向会清空 | `>` 覆盖，`>>` 追加 | 用 `>>` 防止误删 |
| `rm -rf` 没有回收站 | 删错就回不来 | 删之前先 `ls` 看一眼 |
| `mkdir` 已存在会报错 | "File exists" | 加 `-p` 自动忽略已存在 |

## PM 视角

- **文件路径 = 楼栋号**：每一层就是一个层级，写错了找不到
- **"重定向"概念**：是把命令的"嘴"接到文件的"嘴"——理解了这条，管道 `|`、查找 `>` 都通
- **"为什么不用 GUI"**：开发习惯命令行，是因为它**可复现**（同一个命令重跑得到同样结果，鼠标点不行）+ **可分享**（5 行 shell script 甩给别人就是 1 个调试工具）
